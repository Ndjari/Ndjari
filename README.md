## Featured Projects

### ⭐ E-Commerce Financial & Operational Intelligence

End-to-end Data Analytics and Business Intelligence project built with **Python, SQL and Power BI** using the Brazilian Olist e-commerce dataset.

The project covers the complete analytical workflow:

- data cleaning and transformation;
- feature engineering;
- relational analytical modeling;
- financial and operational analysis;
- SQL analytics;
- statistical analysis;
- machine learning for revenue prediction;
- executive dashboards in Power BI;
- business-oriented insights for commercial prioritization.

Key analyses include revenue concentration, estimated profitability, logistics performance, customer satisfaction and short-term revenue forecasting.

🔗 https://github.com/Ndjari/ecommerce-financial-operational-intelligence
